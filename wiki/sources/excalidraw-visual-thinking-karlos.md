## Summary

วิดีโอความยาว 39 นาทีของ Karlos สอนปลั๊กอิน Excalidraw ของ Obsidian — ปลั๊กอินที่ถูกดาวน์โหลดมากที่สุดตลอดกาล (5,451,903 ครั้ง) เริ่มจากวิทยานิพนธ์ว่า การคิดเชิงภาพ (visual thinking) คือกุญแจปลดล็อกไอเดีย (อ้างสมุดโน้ตของ Leonardo da Vinci และการร่างทฤษฎีของ Einstein) และแอปจดโน้ตแบบสมัครสมาชิกที่แยกภาพวาดออกจากกันนั้นเปลืองเงิน เนื้อหาครอบคลุม: การติดตั้ง, Infinite Canvas และคีย์ลัดรูปทรง, การปรับแต่งสไตล์ (sloppiness, fill, colors), การจัดกลุ่มและ Icon Libraries, การฝังกระดานวาดในโน้ต Markdown แบบ real-time, การลิงก์สองทางระหว่างกระดานกับโน้ต, การฝังสื่อโต้ตอบ (ภาพ/GIF/PDF/หน้าเว็บ/โน้ตสด), แนวคิด "Back of note card" (ไฟล์ .excalidraw คือไฟล์ .md จริงๆ), การฝังกระดานซ้อนกระดาน, การตั้งค่าปลั๊กอินที่สำคัญ, Excalidraw Scripts (Invert Colors, Slideshow) และการส่งออก

## Key Claims

- [fact] Karlos — Excalidraw (พัฒนาโดย Zsolt Viczian) เป็นปลั๊กอิน Obsidian อันดับ 1 ใน Community Plugins ที่มียอดดาวน์โหลดสูงสุดตลอดกาล: 5,451,903 ครั้ง (ภาพหน้าจอ [00:05])
- [analysis] Karlos — การคิดเชิงภาพคือกุญแจปลดล็อกไอเดียที่ดีที่สุด (อ้าง da Vinci/Einstein); แอปสมัครสมาชิกที่แยกภาพวาดโดดเดี่ยว (Notability Plus $20/ปี, Pro $99/ปี; Microsoft 365 $9.99–19.99/เดือน) ไม่เชื่อมกับระบบสมองที่สอง จึงเปลืองเงิน
- [analysis] Karlos — "กับดักใหญ่" (Giant Trap) ของมือใหม่: ข้ามพื้นฐาน Obsidian (wikilinks และ embeds) แล้วพุ่งไปวาดรูปเลย — เสียศักยภาพของ Excalidraw ไปถึง ~90%
- [fact] Karlos — กระดาน Excalidraw คือไฟล์ Markdown จริงๆ: เปิด "Open as markdown" จะเห็นโค้ดข้อมูลวาดรูป ตามด้วยข้อความ "back of note card" — วาดกับเขียนอยู่ในไฟล์เดียวกัน
- [analysis] Karlos — การลิงก์สองทาง (ลากโน้ตลงกระดาน, Add link บนรูปทรง, Copy link for the selected element(s)) ยกระดับกระดานวาดเป็น "แผนที่นำทางความรู้" (Knowledge Map); Group Link ฝังได้เฉพาะส่วนของกระดาน
- [analysis] Karlos — Arrow Snapping (หัวลูกศรดูดติดขอบรูปทรง และยืดตามเมื่อย้ายรูปทรง) เหมาะกับการทำ Mind Map; ทุกอย่างเป็น vector graphics ซูมเท่าไรก็ไม่แตกเป็นพิกเซล
- [analysis] Karlos — การฝังกระดานซ้อนกระดาน (nesting drawings) ช่วยย่อยไอเดียใหญ่เป็นชิ้นเล็ก แล้วรวมเป็นภาพใหญ่ (Big Picture View) — แก้ไขกระดานย่อยแล้วกระดานใหญ่ อัปเดตตามทันที
- [analysis] Karlos — Excalidraw Scripts เพิ่มพลังด้วยส่วนขยาย: Invert Colors (dark mode ที่ไม่ทำให้ภาพฝังเพี้ยน) และ Slideshow (เปลี่ยนกระดานที่เชื่อมด้วยลูกศรเป็นสไลด์นำเสนอ)
- [analysis] Karlos — การฝังสื่อโต้ตอบ (PDF as image / embeddable, interactive web frame ผ่าน Alt/Option+drag, live Markdown embeds) ทำให้กระดานเป็นพื้นที่ทำงาน ไม่ใช่แค่ภาพนิ่ง
- [analysis] Karlos — วิธีอ้างอิงไฟล์อัจฉริยะ: ย้าย/เปลี่ยนชื่อไฟล์ที่ฝัง (เช่น duck.jpeg → duck Jeff) แล้ว Obsidian อัปเดตการอ้างอิงทั้งในโน้ตและบนกระดานให้อัตโนมัติ
