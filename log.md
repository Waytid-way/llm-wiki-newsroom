That needs no new group and is left as the open item.

Checking the port frontier turned up a stale checkpoint: the carryover note pointed three rounds behind where the mirror actually stood, because the index line and the note's own description had drifted from its body. Reviewing from the wrong commit would have re-proposed six already-absorbed changes. The body checkpoint is now the single authority for that, and says so.

The substantive change is G2. Every `## Key Claims` line had to open with a wikilink claimant, while the naming policy instructs the opposite for a speaker below the entity-addition threshold: carry them as plain text, because a link to a page that does not exist leaves only a broken link. A source citing such a speaker therefore could not pass. The two exits an author actually had were to register the file in the permanent whitelist or to link some nearby entity that had not said the thing — a required check manufacturing the misattribution it exists to prevent, with the whitelist absorbing the evidence that it was happening. What WP:ASF asks for is a named source; the wikilink is one means to it. The criterion now measures naming, and three screens replace the link requirement: an anonymous or collective subject fails in either form, a head longer than a name fails so content cannot be pushed into the slot, and plain text naming a page that does exist fails as link evasion. On this corpus G2 goes 3/4 to 4/4 with four plain-text claimants recognised, and the whitelist empties — its only entry was justified by "plain text, so no wikilink", which is now a supported pass path.

The anonymity screen is a local design, not a translation. The engine splits Korean weasels into a suffix form that means a collective wherever it attaches and a word form that can sit inside a proper institution name and so is tested only as the final word. English needs neither split, because case does the work: `Free Software Foundation` is a name and `the foundation` is not. One lowercase-gated last-word list carries it. The failure mode both designs guard against is the same one, and the engine found it the hard way — a denylist without that boundary drops the very names the guideline offers as correct examples.

The claimant-selection tree lost two steps in the same pass. Where the speaker had no page it told the author to take the first entity linked in `## Connections`, or the source's dominant concept hub. Both answer "who said this" with a different actor, and with plain text now available there is nothing left for them to stand in for. Six documents restated the retired contract in the imperative and were synchronised with the check. Two smaller drops came along: the contradiction drift note printed the first three slugs of each set, so a worker reading four saw three with no signal the list was cut, and `mine_feedback` excluded relay traffic by prefix while excluding notifications by substring — a relay arrives behind a preamble, so the prefix test let it through and its text was mined as though the operator had said it. The relay defect matters now rather than later, since no review watermark exists here yet and the first run would have inherited it.
