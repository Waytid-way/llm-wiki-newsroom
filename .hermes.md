# LLM Wiki Newsroom — Hermes project rules

Source of truth: **CLAUDE.md + `.claude/`** (5-role newsroom flow, 9 slash
commands, deterministic `tools/` pipeline). Read `CLAUDE.md` fully before deep
work — this file only bridges the rules Hermes must never miss. (Note:
`AGENTS.md` is legacy-compat and self-deprecating; do not treat it as the SoT.)

## Non-negotiable (from CLAUDE.md)

1. Never hand-edit generated artifacts: `wiki/index.md`,
   `wiki/sources/_catalog*.md`, any `<!-- AUTO:* BEGIN/END -->` region, or
   `graph/_*.json` (exception: `graph/cluster_labels.json` is operator-edited)
   — rerun `python tools/build.py` instead.
2. Never hand-write `graph/graph.html` or `graph/_*.json` — the HTML is a
   committed Sigma.js shell that fetches build artifacts.
3. Run `python tools/lint.py`; exit 0 is the publication gate (exit 1 with
   exactly the 2 pre-existing FAIL groups is the clean working-tree baseline:
   "4 broken source_file reference" + "2 meta-schema issue").
4. `raw/` is immutable. English TitleCase filenames by default (native-script
   filenames allowed per `.claude/policies/naming.md`); new person stubs need
   ≥3 distinct citing sources + operator approval.

## Hermes operational notes

- Verify protocol for any change: `python3 -W error::SyntaxWarning -m
  compileall -q tools tests .claude/hooks` → `python3 -m pytest tests/ -q`
  (baseline 251) → `python3 tools/lint.py` == baseline above.
- Ad-hoc verification scripts: write as `hermes-verify-*.py` under
  `/data/data/com.termux/files/usr/tmp` (the only reliable temp dir on this
  Termux box), run, then delete. Never use heredocs to write files into the
  repo (blocked by the terminal guard).
- Parallel implementation: `git worktree` per batch, ≤3 concurrent subagents,
  rebase-then-FF merge (rebase sequentially, one at a time, after each merge).
- Use `tools/_lib.py` helpers as the single source of truth (H2_RE,
  section_body, strip_fences, parse_frontmatter, WIKI_SUBDIRS…); findings that
  re-implement them are inconsistencies. Skill `checks.py` files are
  lint-measured: keep exported function names and dotted IDs stable.
- Hub/cluster community detection falls back to pure-Python
  `tools/_build/_leiden_py.py` when igraph/leidenalg are absent — never
  require the C libraries on this machine.
